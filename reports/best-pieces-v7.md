## 五绝 · 山中月夜（王维风格）

```
月出山欲空，清光落寒松。
幽人独对此，不觉夜来钟。
```
押韵：空 / 松 / 钟（东冬）· 抄袭重叠 0.00

## 五绝 · 秋夜（模型采样）

```
秋夜月如霜，江风吹冷香。
独坐听疏雨，愁心与雁长。
```
押韵：霜 / 香 / 长（阳韵）

## 七绝 · 江边送别

```
江天潮落月西流，客棹孤帆逐远鸥。
挥手不知人万里，一灯寒雨满离舟。
```
押韵：流 / 鸥 / 舟（尤韵）

## 七绝 · 田园初夏（袁枚风格）

```
秧针已绿麦初黄，水满陂塘柳正长。
日午荷香风细细，不知身在稻田旁。
```
押韵：黄 / 长 / 旁（阳韵）

## 七绝 · 清诗（早春）

```
绿杨村外麦初黄，小径苔深鸟雀忙。
雨过溪声如笛语，一锄新水到秧塘。
```
押韵：黄 / 忙 / 塘（阳韵）
